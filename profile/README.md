## What is this?

Real computers are enormous. The ideas inside them are not.

**Tiny Computers** is a series of small projects that rebuild the core of GPUs, TPUs, CPUs and compilers in a form you can read in an afternoon, run on your own machine, and actually understand. Each project strips a system down to its essential mechanism and makes it visible.

## The series

| Project | What it shows | Links |
|---|---|---|
| [**tiny-gpu**](https://github.com/tinycomputers/tiny-gpu) | How parallel threads, registers, memory and instructions work on a GPU, in a Python simulator | [Live demo](https://tinycomputers.github.io/tiny-gpu/) |
| [**tiny-tpu**](https://github.com/tinycomputers/tiny-tpu) | A real SystemVerilog systolic array, compiled to WASM and visualized live in the browser | [Live demo](https://tiny-tpu.vercel.app) |
| **tiny-cpu** | A minimal CPU, from instruction set to execution | *In progress* |
| **tiny-compiler** | Source code to executable instructions, end to end | *In progress* |
| **tiny-attention** | The attention mechanism behind modern AI models, from first principles | *In progress* |

More are on the way.

## Principles

- **Small.** If it does not fit in your head, it is not tiny enough.
- **Readable.** Code and docs are written to be learned from.
- **Real.** Simplified, never fake. The mechanisms are the ones real hardware and software use.
- **Visible.** Where possible, you can watch it run.
